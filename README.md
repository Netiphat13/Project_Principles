# ฟีเจอร์หลัก
- สมัครสมาชิก / เข้าสู่ระบบด้วยอีเมลที่สมัครไว้ (รหัสผ่านเก็บแบบ BCrypt)
- สร้างบิล 5 ขั้น (ข้อมูลบิล → สมาชิก → รายการอาหาร → วิธีหาร → สรุป) บันทึกลง PostgreSQL
- รหัสเข้าร่วมบิล (`SM-XXXXXX`) และลิงก์เชิญ `/join?code=...`
- เชิญเพื่อนที่มีบัญชีด้วยอีเมล เพื่อนกดยอมรับ/ปฏิเสธที่กระดิ่งแจ้งเตือน
- แนบสลิป/ใบเสร็จของบิล (JPG, PNG, WEBP, GIF, PDF ไม่เกิน 8 MB เก็บที่ `code/uploads/slips`)
- บิลของฉัน / แดชบอร์ด / สถิติ แสดงทั้งบิลที่สร้างเองและบิลที่เข้าร่วม
- โปรไฟล์ (ชื่อ เบอร์โทร แนะนำตัว) และการตั้งค่าแจ้งเตือนบันทึกในฐานข้อมูล
